# PILATES ONE STEP ホームページ（リニューアル版）

## フォルダ構成
- `site/` … 公開用のファイル一式。この中身をサーバーの公開ディレクトリ（ドメイン直下）にアップロードします。
  - URLは現サイトと同じです（`/about/` `/price/` `/flow/` `/faq/` `/contact/` `/news/` `/news/269/` など、`/policy/` `/terms/` `/law/`）。
  - `sitemap.xml` `robots.txt` `404.html` も含みます。
- `preview/` … 確認用。`preview/index.html` をダブルクリックすればブラウザで全ページを見られます（アップロードには使いません）。
- `_build/build.py` … ページを生成するスクリプト。ヘッダー・フッター・各ページの文章・お知らせはここで管理しています。
- `image/` `HP_sample/` … 元素材（アップロード不要）。

## 修正・お知らせ追加のしかた
1. `_build/build.py` を編集します（お知らせは `NEWS = [...]` の先頭に追加）。
   - お知らせ一覧のページ送りは、カードが `NEWS_PER_PAGE`（8件）を超えると自動で表示されます。先頭の大きな記事は別枠で1ページ目に出ます。
2. 次のコマンドで `site/` を作り直します。

```
python3 _build/build.py
```

写真は `image/` フォルダの元画像を同じ名前で差し替えたあと、**必ず `python3 _build/build.py` を実行してください**（実行しないとサイトには反映されません）。ビルド時に、前回から変わった写真だけ自動でWeb用に縮小・圧縮して `site/assets/img/` に反映します。更新日時が古いままコピーした写真でも、ファイルの中身が変わっていれば差し替わります。画像のURLには中身に応じた番号（`?v=…`）が付くので、ブラウザに古い画像が残ることもありません。新しい写真を使う場合は `_build/build.py` の `PHOTOS` に追加してください。人物を切り抜いて使う写真（トップの料金「プライベートレッスン」）は `CUTOUTS` で指定しており、ビルド時にMac標準の人物認識で背景を自動で取り除きます。

トップページのキャッチ「今日の一歩が、明日のわたしを変える。」は `image/catch.svg`（Illustratorでアウトライン化したもの）を使っています。差し替えるときは同じ名前で上書きしてビルドしてください。黒（#231815）はサイトの紺色に自動で置き換わります。ピンクの線の位置は `style.css` の `.hero-catch__stroke` で調整します。

料金横の「好きなだけ通える！」は `image/subcatch.svg` をそのままの色で使っています。差し替えは同じ名前で上書きしてビルドしてください。大きさは `style.css` の `.suki` の幅で調整します。

デザインの変更は `site/assets/css/style.css` を直接編集します。

## 公開前にやること
- **お問い合わせフォームのメールアドレス**：送信処理は `site/contact/send.php`（PHP）です。ファイル冒頭の2行を設定してください。
  - `MAIL_TO` … お問い合わせを受け取るアドレス（初期値 `info@onestep-p.jp` は仮）
  - `MAIL_FROM` … 送信元アドレス。迷惑メール扱いを避けるため、サーバーと同じドメイン（`@onestep-p.jp`）のアドレスにしてください。
  - 送信後は `/contact/thanks/`（完了ページ）へ移動し、お客様には自動返信メールが届きます。
  - 公開後、実際にフォームから1件送信して、両方のメールが届くか確認してください。
- 公開後、Google Search Console に `https://onestep-p.jp/sitemap.xml` を送信してください。
